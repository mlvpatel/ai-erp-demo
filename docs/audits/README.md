# Audit records

Audit documents are dated snapshots, not current product authority. Keep only
sanitized findings and remediation status here: no absolute workstation paths,
customer identities, private contacts, credentials, or raw external reports.

Re-check every finding against the current commit and the repository quality
gates before acting on it.
